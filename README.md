# 💜 Gitgram

A Flutter application that helps developers explore GitHub profiles and discover public repositories in a beautiful interface.

## ✨ Features

- 🔍 Search GitHub users by username.
- 👤 View developer profiles and avatars.
- 📝 Explore developer bios and locations.
- 📦 Discover public repositories.
- ⭐ View repository stars and programming languages.
- 👥 Check followers and following.
- 🕒 Access recent search history.
- 🔗 Open GitHub profiles and repositories directly.

## 🛠️ Tech Stack

- Flutter
- Dart
- GitHub REST API
- HTTP
- Shared Preferences
- URL Launcher

## 🚀 Getting Started

Clone this repository:

```bash
git clone https://github.com/anusha123953/gitgram.git
```

Navigate to the project:

```bash
cd gitgram
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run -d chrome
```
