
# Gitgram 💜

A Flutter application to explore GitHub developer profiles and repositories.

## Features
- Search GitHub users.
- View developer profiles and avatars.
- Explore public repositories.
- View followers and following.
- Check repository stars and programming languages.
- Save recent searches.
- Open GitHub profiles and repositories.

## Tech Stack
- Flutter
- Dart
- GitHub REST API
- HTTP
- Shared Preferences
- URL Launcher

## Run Locally

```bash
git clone https://github.com/anusha123953/gitgram.git
cd gitgram
flutter pub get
flutter run -d chrome
